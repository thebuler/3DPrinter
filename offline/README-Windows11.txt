와우고등학교 3D 프린팅 안내 - 오프라인 버전

실행 방법
1. ZIP 파일을 Windows 11에서 압축 풉니다.
2. 압축을 푼 폴더 안의 start-offline.bat을 더블 클릭합니다.
3. 설치된 Chrome에서 http://127.0.0.1:8765/ 페이지를 엽니다. 자동으로 열리지 않으면 이 주소를 Chrome에 입력합니다.
4. 사용을 마치면 검은색 서버 창을 닫습니다.

인터넷, Node.js, Python 설치 없이 사용할 수 있습니다. Windows 11에 기본 포함된 PowerShell을 사용합니다. 서버는 이 PC 안에서만 열리며 인터넷으로 신고를 전송하지 않습니다. 폴더 안의 파일 이름이나 위치를 바꾸지 마세요.

오프라인 고장 신고
- 신고는 이 PC의 Chrome 프로필에만 저장됩니다. 다른 PC나 다른 Chrome 프로필과 공유되지 않습니다.
- Chrome의 해당 사이트 데이터가 삭제되거나 이 폴더를 다른 위치로 옮기면 오프라인 신고가 보이지 않을 수 있습니다.
- 신고 수정, 삭제, 처리 상태 변경은 관리자 인증이 필요한 온라인 버전에서 이용해 주세요.
- 이 버전에는 실제 관리자 비밀번호와 온라인 신고 기록이 포함되어 있지 않습니다.
