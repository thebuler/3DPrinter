# 와우고등학교 3D 프린팅 안내

학생용 3D 프린터 사용 안내, 문제 해결, 기기 번호별 고장 신고 웹앱입니다.

## 실행 방법

1. Node.js와 npm이 설치된 컴퓨터에서 프로젝트 폴더를 엽니다.
2. `environment.example`을 복사해 `.env` 파일로 이름을 바꾸고 `REPORT_ADMIN_PASSWORD`에 관리자 비밀번호를 설정합니다.
3. 터미널에서 `npm run dev`를 실행합니다.
4. 브라우저에서 `http://localhost:3000`을 엽니다.

## 신고 데이터와 관리자 기능

- 로컬 미리보기는 신고를 `data/reports.json`에 저장합니다. 이 파일은 신고가 처음 등록될 때 자동 생성됩니다.
- Vercel 배포는 `api/` 서버 함수와 Supabase 데이터베이스를 사용합니다. 설정 방법은 `VERCEL-SUPABASE-SETUP.md`를 참고하세요.
- 관리자 비밀번호는 서버에서만 사용됩니다. 실제 비밀번호가 들어 있는 `.env` 파일은 다른 사람과 공유하지 마세요.
- 다운로드용 압축 파일에는 비밀번호 파일과 기존 신고 데이터가 포함되지 않습니다. 기존 기록을 Supabase로 옮기려면 `data/reports.json`을 별도로 안전하게 백업한 뒤 가져와야 합니다.
